# Runtime Setup



## Overview

The runtime setup for tabular orchestration in SAP AI Core consists of creating a deployment one time and then consuming the deployed service at runtime.



## Step 1: Create a Deployment for Tabular Orchestration

Create the deployment for tabular orchestration in SAP AI Core. This setup step is required only once per resource group.

For the complete setup procedure, see **[Create a Tabular AI Deployment](create-a-tabular-ai-deployment-db2da6d.md)**.



## Step 2: Consume Tabular AI Orchestration Service

After the deployment is in the `RUNNING` state, consume the tabular AI orchestration service using the deployment URL.

For detailed consumption steps and API usage, see **[Consume Tabular Orchestration](consume-tabular-orchestration-1cdac20.md)**.

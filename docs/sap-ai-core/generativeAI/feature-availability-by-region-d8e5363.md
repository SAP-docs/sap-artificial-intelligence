# Feature Availability by Region

Use this regional availability matrix to find out which generative AI features are available across SAP's global data centers. The tables show which AI capabilities \(such as LLM Orchestration and Prompt Registry\) are accessible in your specific geographic region.



## How to Read These Tables

In the tables below, AI and machine learning features are listed as follows:


<dl>
<dt><b>

Yes

</b></dt>
<dd>

The feature is available and accessed from within that region.



</dd><dt><b>

No

</b></dt>
<dd>

The feature isn't available in the specified region.



</dd>
</dl>

Information provided in these tables is maintained on a best-effort basis.
